    Kode micro:bit, cara melatih gestur, dan catatan pemakaian

    1. Protokol perintah

    Konsol ini mengirim teks polos — satu perintah per baris — lewat layanan UART Bluetooth milik micro:bit: up, down, left, right, stop, ditambah speed:180 untuk laju motor dan beep untuk klakson. Perintah yang sama dipakai baik oleh D-pad maupun hand gesture, jadi robot tidak perlu program berbeda.

    2. Program untuk micro:bit

    1. Buka makecode.microbit.org, lalu buat proyek baru.
    2. Tambahkan ekstensi Bluetooth, lalu ekstensi Tiny:bit lewat URL https://github.com/YahboomTechnology/Tiny-bitLib.
    3. Masuk ke Project Settings dan pilih No Pairing Required supaya browser bisa langsung menyambung.
    4. Tempel kode berikut di tab JavaScript, lalu flash ke micro:bit.
    5. Nyalakan Tiny:bit, kembali ke halaman ini, tekan Hubungkan micro:bit, dan pilih perangkat BBC micro:bit.
    let perintah = ""
let laju = 180

bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    perintah = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))
    if (perintah.substr(0, 6) == "speed:") {
        laju = parseFloat(perintah.substr(6, perintah.length - 6))
    } else if (perintah == "beep") {
        music.playTone(988, music.beat(BeatFraction.Quarter))
    } else if (perintah == "up") {
        basic.showArrow(ArrowNames.North)
        Tinybit.CarCtrlSpeed(Tinybit.CarState.Car_Run, laju)
    } else if (perintah == "down") {
        basic.showArrow(ArrowNames.South)
        Tinybit.CarCtrlSpeed(Tinybit.CarState.Car_Back, laju)
    } else if (perintah == "left") {
        basic.showArrow(ArrowNames.West)
        Tinybit.CarCtrlSpeed(Tinybit.CarState.Car_SpinLeft, laju)
    } else if (perintah == "right") {
        basic.showArrow(ArrowNames.East)
        Tinybit.CarCtrlSpeed(Tinybit.CarState.Car_SpinRight, laju)
    } else if (perintah == "stop") {
        basic.showIcon(IconNames.Square)
        Tinybit.CarCtrl(Tinybit.CarState.Car_Stop)
    }
})

bluetooth.onBluetoothConnected(function () {
    basic.showIcon(IconNames.Yes)
})

bluetooth.onBluetoothDisconnected(function () {
    Tinybit.CarCtrl(Tinybit.CarState.Car_Stop)
    basic.showIcon(IconNames.No)
})

bluetooth.startUartService()
basic.showIcon(IconNames.Heart)

    3. Melatih gestur di Teachable Machine

    1. Buka Teachable Machine → Image Project, pilih Standard image model.
    2. Buat kelas sesuai gestur tangan, misalnya maju, mundur, kiri, kanan, dan satu kelas netral untuk tangan terbuka atau layar kosong.
    3. Rekam contoh lewat webcam, kira-kira 150–300 gambar per kelas. Variasikan jarak, sudut, dan pencahayaan supaya model tidak kaku.
    4. Tekan Train Model, tunggu sampai selesai, lalu Export Model → TensorFlow.js → Upload my model dan salin tautannya.
    5. Tempel tautan itu ke kolom tautan model di panel atas, tekan Muat model, lalu pasangkan setiap kelas ke perintah. Kelas netral sebaiknya dipetakan ke stop.

    Kelas netral itu penting: dialah yang membuat robot berhenti saat kamu menurunkan tangan. Kalau tidak ada, konsol tetap aman karena ada auto-stop yang mengirim stop begitu tidak ada kelas yang cukup yakin selama jeda yang kamu atur.

    4. Cara konsol membaca kamera

    Pustaka TensorFlow.js dan @teachablemachine/image baru diunduh saat kamu menekan Muat model, jadi mode Bluetooth tetap ringan. Gambar dari kamera diprediksi sekitar 10 kali per detik, lalu disaring tiga lapis sebelum dikirim ke robot: ambang keyakinan, frame stabil, dan auto-stop. Semua hasil prediksi muncul di batang keyakinan langsung supaya bisa dipakai menjelaskan cara kerjanya saat presentasi.

    5. Simulator, rutin, dan latihan akurasi

    Simulator lintasan menggambar robot bayangan yang mengikuti setiap perintah — dari D-pad, keyboard, maupun gestur — lengkap dengan jejak jalurnya. Jarak dan sudutnya dihitung dari laju motor dan lama perintah ditahan, jadi anggap sebagai perkiraan bentuk lintasan, bukan ukuran pasti di lantai. Tombol Bersihkan jejak dan Kembali ke titik awal ada di sebelahnya.

    Rekam rutin menyimpan urutan perintah beserta jeda waktunya. Tekan Rekam rutin, kemudikan robot seperti biasa, lalu tekan Selesai rekam. Tombol Putar mengulang urutan itu persis dengan jeda yang sama; begitu kamu menyentuh D-pad atau keyboard, rutin otomatis berhenti dan kendali kembali ke tanganmu. Rutin tersimpan di browser, jadi masih ada setelah halaman ditutup.

    Latihan akurasi gestur menampilkan nama kelas secara acak, lalu mencatat kelas mana yang sebenarnya dibaca model. Hasilnya berupa jumlah percobaan, persentase akurasi, rerata waktu reaksi, dan matriks kebingungan yang memperlihatkan pasangan kelas mana yang sering tertukar — angka-angka ini bisa langsung dipakai di laporan. Robot tidak digerakkan selama latihan, jadi aman dicoba di atas meja.

    6. Catatan pemakaian

    • Web Bluetooth berjalan di Chrome dan Edge pada Windows, macOS, Linux, dan Android. Safari serta iOS belum mendukungnya.
    • Kamera dan Bluetooth hanya aktif di halaman https:// atau localhost. GitHub Pages sudah https, jadi aman.
    • Kalau tombol Hubungkan ditolak karena halaman tampil di dalam bingkai, buka dulu tautan konsol ini di tab penuh.
    • Tanpa perangkat pun konsol tetap hidup: semua perintah berjalan dalam mode uji dan tetap tercatat di log, jadi D-pad, gestur, dan urutan perintahnya bisa diperiksa lebih dulu.
    • Untuk mengunggah ke GitHub Pages, ganti nama berkas ini menjadi index.html, dorong ke repositori, lalu aktifkan Pages di Settings → Pages.
